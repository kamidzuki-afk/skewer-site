Skewer — сайт для приёма заказов

Сайт-визитка вайбкодера Ивана (Skewer) с личными кабинетами клиентов и админ-панелью. Клиент оформляет заказ прямо на сайте и следит за его статусом, а владелец принимает заявки и управляет ими в одном месте.

🔗 Демо: https://skewer-site.onrender.com

Сайт работает на бесплатном хостинге (пробный запуск), поэтому первое открытие после паузы может занять до минуты. Дальше страницы грузятся быстро.

Возможности

Для клиента

	•	Регистрация и вход, аккаунт работает с любого устройства
	•	Личный кабинет: профиль, смена аватарки, количество заказов и сумма трат
	•	Статус текущего заказа с описанием и историей этапов: «Ожидание подтверждения» → «Выполнение» → «Заказ готов и выдан»
	•	Калькулятор примерной стоимости проекта
	•	Автоматическая система скидок (5 / 10 / 15 / 20%), которую клиент не может выбрать вручную
	•	Форма заявки очищается после отправки, аккаунт хранит только имя и почту

Для владельца

	•	Админ-панель: все заявки с полной информацией о клиенте, контактом, услугой и ТЗ
	•	Смена статуса заказа и назначение стоимости, клиент видит изменения сразу
	•	Необязательное уведомление о новом заказе в Telegram
	•	Блок «Работы» сам подтягивает проекты с GitHub, у которых стоит тема portfolio

Технологии

	•	Сервер: Node.js, без фреймворков (встроенный модуль http)
	•	База данных: PostgreSQL (Neon)
	•	Клиент: один файл index.html, чистые HTML, CSS и JavaScript
	•	Хостинг: Render
	•	Безопасность: пароли хранятся в виде хэша scrypt с солью, сессии в подписанных HttpOnly cookie, ограничение попыток входа, защитные заголовки (CSP, HSTS)

Структура проекта

server.js      сервер: API, аккаунты, заказы, админка, GitHub, Telegram
index.html     сайт целиком: интерфейс, кабинет клиента, админ-панель
package.json   зависимости и команда запуска

Запуск

	1.	Создайте базу PostgreSQL (например, на neon.tech) и скопируйте строку подключения.
	2.	Задайте переменные окружения:

Переменная	Назначение
DATABASE_URL	строка подключения к PostgreSQL
SESSION_SECRET	длинная случайная строка для подписи сессий
ADMIN_EMAIL	почта для входа в админ-панель
ADMIN_PASSWORD	пароль администратора
GITHUB_USER	аккаунт GitHub, откуда берутся работы
PORTFOLIO_TOPIC	тема репозиториев для портфолио (по умолчанию portfolio)
BOT_TOKEN, OWNER_ID	необязательно: уведомления о новых заказах в Telegram
GITHUB_TOKEN	необязательно: повышает лимит запросов к GitHub

	3.	Установите зависимости и запустите:

npm install
npm start

Таблицы в базе создаются автоматически при первом запуске.

Как добавить работу в портфолио

Откройте репозиторий на GitHub, добавьте ему тему (Topic) portfolio и заполните описание. Через несколько минут проект появится на сайте.
